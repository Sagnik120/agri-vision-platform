# Codebase File-by-File Guide

## `README.md`
**Role:** Main project overview and documentation.
**Component:** Documentation.
**Status:** IMPLEMENTED
**Responsibilities:** Describes the SIH/MHTECHIN problem statement, the 3-Zone architecture, offline-first capabilities, and setup instructions.

## `contract.md`
**Role:** Formal data contract specification.
**Component:** Architecture/Contracts.
**Status:** IMPLEMENTED
**Responsibilities:** Defines strictly frozen JSON schemas for payload exchange between Zone 1, Zone 2, and the UI. It governs the shapes of Image output, farmer text, Text evidence, Sensor data, Fusion output, and Cloud payloads.

## `src/app/streamlit_app.py`
**Role:** Main farmer-facing Streamlit application.
**Component:** Application/UI layer.
**Status:** IMPLEMENTED
**Responsibilities:** 
- Renders bilingual UI (English/Hindi).
- Handles user authentication (Login/Signup).
- Collects inputs: Image, Text, Simulated Sensor data.
- Invokes `run_zone1_pipeline`.
- Branches UI logic based on `route` (local vs cloud).
- Calls Gemini client and DB logging.
**Important Notes:** Contains custom CSS. Integrates directly with all 3 zones.

## `src/zone1_edge/pipeline.py`
**Role:** THE end-to-end orchestrator for Zone 1.
**Component:** Edge AI Orchestrator.
**Status:** IMPLEMENTED
**Responsibilities:** 
- Runs quality checks.
- Dispatches to `task_router`.
- Invokes text and sensor processors.
- Merges data via `fusion.py`.
- Finalizes routing via `confidence_gate.py`.
- Fetches `local_advisory` if routed locally.
**Key Functions:**
- `run_zone1_pipeline()` — Orchestrates the full sequence.
- `build_cloud_payload_stub()` — Formats contract #6.

## `src/zone1_edge/task_router/task_router.py`
**Role:** Routes image tasks to specific domain experts.
**Component:** Edge Task Router.
**Status:** IMPLEMENTED
**Responsibilities:** 
- Evaluates domain manually from UI or dynamically via `auto_route`.
- In `auto` mode, uses a Hugging Face Zero-Shot Classifier pipeline (`transformers`) to semantically classify if an image is a plant or an animal.
- Falls back to raw math comparison in `mock` mode.

## `src/zone1_edge/experts/crop_expert.py` & `livestock_expert.py`
**Role:** Domain-specific vision classifiers.
**Component:** Edge Vision Models.
**Status:** IMPLEMENTED
**Responsibilities:** 
- Wrap `BaseImageExpert`.
- Run inference against PyTorch/HF vision models.
- Output predictions matching JSON contract #1.
**Important Notes:** Use `CROP_MOCK_LABELS` and `LIVESTOCK_MOCK_LABELS` respectively as mock fallbacks. Livestock expert also contains zero-shot text mappings.

## `src/zone1_edge/multimodal/fusion.py`
**Role:** Rule-based late fusion engine.
**Component:** Evidence Aggregator.
**Status:** IMPLEMENTED
**Responsibilities:** 
- Combines visual confidence with text and sensor support.
- Adds specific mathematical bonuses/penalties (+0.10, -0.20, etc.) based on whether text/sensors support or contradict visual predictions.
- Sets a provisional `route`.
**Important Notes:** Uses deterministic, hard-coded condition-symptom maps rather than a learned neural network.

## `src/zone1_edge/multimodal/confidence_gate.py`
**Role:** Final decision layer for cloud escalation.
**Component:** Routing Authority.
**Status:** IMPLEMENTED
**Responsibilities:** 
- Evaluates fusion outputs, input quality, and safety criticality.
- Forces `route = 'cloud'` if confidence < threshold (0.80 for critical, standard otherwise), if symptoms conflict, or if quality is poor.

## `src/zone2_cloud/rag/retriever.py`
**Role:** Local Knowledge Base Retriever.
**Component:** Cloud/RAG layer.
**Status:** IMPLEMENTED
**Responsibilities:** 
- Uses `faiss` and `sentence-transformers/all-MiniLM-L6-v2` to vectorize and query localized farming knowledge.
- Returns top-k context snippets.
**Dependencies:** Depends on index files generated by `build_knowledge_base.py`.

## `src/zone2_cloud/gemini/gemini_client.py`
**Role:** Cloud LLM Interface.
**Component:** Cloud AI layer.
**Status:** IMPLEMENTED
**Responsibilities:** 
- Calls Google Gemini Pro (`google-genai`) with highly engineered system prompts.
- Packages image, transcript, sensor data, DB history, and RAG into context.
- Parses output into strictly validated JSON schemas.
**Important Notes:** Features a `MockGeminiClient` for robust offline testing and development when `GEMINI_ENABLED=false`.

## `src/zone3_memory/db/farm_memory.py`
**Role:** Local Private History Store.
**Component:** Database layer.
**Status:** IMPLEMENTED
**Responsibilities:** 
- Interacts with a local SQLite DB using Python standard library `sqlite3`.
- Saves observations, diagnoses, and advisories to specific tables.
- Synthesizes formatted historical context strings via `get_farm_history()` for ingestion into Gemini.

## `tests/`
**Role:** Unit and integration testing.
**Component:** Testing.
**Status:** IMPLEMENTED
**Responsibilities:** Covers all critical zones. Tests components in isolation and end-to-end pipelines. Uses `pytest`.
