# Wheat Rust

**Description:** Fungal disease causing orange/brown pustules on wheat leaves.

**Safety Critical:** False

## Actions
- Apply systemic fungicides (e.g. tebuconazole) at first sign.
- Use resistant wheat varieties in future.

## Warning
Can cause severe yield loss if not treated before heading.
