# Soybean Rust

**Description:** Aggressive fungal disease causing premature defoliation in soybean.

**Safety Critical:** False

## Actions
- Apply fungicide immediately upon detection.
- Ensure good canopy penetration of spray.

## Warning
Can spread rapidly by wind.
