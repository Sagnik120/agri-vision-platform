# Poultry Avian Influenza

**Description:** Highly contagious viral disease in poultry causing sudden death and respiratory distress.

**Safety Critical:** True

## Actions
- Isolate the flock immediately.
- Report to veterinary authorities.
- Implement strict biosecurity and cull infected birds.

## Warning
Zoonotic potential! Notify authorities immediately.
