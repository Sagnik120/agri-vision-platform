# Cotton Bollworm

**Description:** Pest larvae that feed on cotton bolls, destroying the fiber.

**Safety Critical:** False

## Actions
- Monitor with pheromone traps.
- Apply targeted insecticides if threshold is reached.
- Destroy crop residues after harvest.

## Warning
Pests can develop resistance; rotate chemicals.
