# Citrus Canker

**Description:** Bacterial disease causing raised corky lesions on citrus leaves, stems, and fruit.

**Safety Critical:** False

## Actions
- Use copper-based sprays preventatively.
- Prune and destroy infected branches.
- Decontaminate tools between trees.

## Warning
Highly contagious in wet conditions.
