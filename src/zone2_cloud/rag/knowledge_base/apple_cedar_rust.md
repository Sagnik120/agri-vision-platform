# Apple Cedar Rust

**Description:** Fungal disease needing juniper/cedar hosts to complete its cycle.

## Symptoms
- Bright yellow-orange spots on leaves, sometimes on fruit.

## Actions
- Remove heavily infected leaves.
- Monitor nearby juniper hosts.

## Prevention
- Plant resistant varieties.
- Remove nearby alternate hosts where feasible.

## Warning
Consult an expert if defoliation is heavy.
