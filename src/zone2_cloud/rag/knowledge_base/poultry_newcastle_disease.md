# Poultry Newcastle Disease

**Description:** Viral disease in birds causing twisting of the neck, paralysis, and drop in egg production.

**Safety Critical:** True

## Actions
- Vaccinate healthy birds immediately.
- Isolate sick birds.
- Disinfect premises thoroughly.

## Warning
Highly contagious; strict quarantine required.
