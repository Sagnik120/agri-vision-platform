# Crop Phosphorus Deficiency

**Description:** Nutrient deficiency causing dark green leaves with purplish discoloration, especially on leaf edges.

**Safety Critical:** False

## Actions
- Apply phosphorus-based fertilizer (e.g., DAP or superphosphate) near the root zone.
- Check soil pH; high acidity or alkalinity can lock up phosphorus.

## Warning
Can delay crop maturity and reduce root development.
