# Crop Nitrogen Deficiency

**Description:** Nutrient deficiency causing overall yellowing of older leaves and stunted growth.

**Safety Critical:** False

## Actions
- Apply a nitrogen-rich fertilizer (e.g., urea) immediately.
- Ensure soil moisture is adequate to allow nutrient uptake.

## Warning
Prolonged deficiency will severely reduce yield.
