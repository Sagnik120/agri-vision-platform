# results/zone1/livestock_model/

Same pattern as crop_model/ — output artifacts (predictions, model_info,
benchmarks) for the livestock expert, generated by running:
    python -m src.zone1_edge.experts.livestock_expert demo_data/livestock/<image>.jpg

If the fallback generic backbone (microsoft/resnet-50) was used instead of a
cattle-specific checkpoint, note that here in model_info.json so Person B's
Gemini prompt and the UI can flag "low-confidence generic model" if needed.
